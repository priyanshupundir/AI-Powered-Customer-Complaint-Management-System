# Sample Complaint Documents

This folder contains sample pharmaceutical complaint documents for testing the document extraction functionality.

## Documents

### 1. sample_complaint_1.txt
- **Product**: Amoxicylin Capsules 500 mg
- **Batch**: AMX-2024-0892
- **Issue**: Discolored capsules
- **Reporter**: Apollo Pharmacy
- **Affected Quantity**: 48 capsules

### 2. sample_complaint_2.txt
- **Product**: Metformin Hydrochloride API
- **Grade**: IP/BP
- **Batch**: MFH260712A
- **Issue**: Appearance/color variation, assay failure
- **Reporter**: MedSupply Distributors
- **Affected Quantity**: 50 kg in 2 HDPE drums

### 3. sample_complaint_3.txt
- **Product**: Ciprofloxacin Tablets 500 mg
- **Batch**: CHG260712A
- **Issue**: Tablet hardness/friability, packaging integrity
- **Reporter**: Regional Hospital Center
- **Affected Quantity**: 200 tablets

## Usage

These documents can be used to test the document extraction AI tool:

1. In the AI Copilot interface, click the attachment icon
2. Select one of these sample documents
3. The AI will extract complaint information and populate the form
4. You can then use natural language to edit the extracted information

## Note

These are sample documents created for demonstration purposes. They contain realistic pharmaceutical manufacturing data but are not based on actual incidents.
